# Changelog

## 0.2.0 — 1 Nov 2026

You can trim and join audio and video, and the editor uses a paper and ink theme.

- Select the player in Live or Track to open the timeline
- A WAV edit is saved; other audio and video play it and refuse export
- View mode still has play, pause, and mute

## 0.0.6 — 31 Oct 2026

The docs list the file types, the events the viewer emits, and how to place a custom component.

- The playground is the code sample for each framework
- Bundles load as plaintext from the CDN

## 0.0.5 — 31 Oct 2026

The SDK docs count visits with Google Analytics.

## 0.0.4 — 31 Oct 2026

The version moved to 0.0.4 to match the other repos.

## 0.0.3 — 31 Oct 2026

The docs send you back to the site on this domain.

## 0.0.2 — 31 Oct 2026

You can copy a UI kit into a framework app and open files from a versioned CDN.

- A headless store drives the viewer without painting the page
- The PDF renderer is read from inside the pdf bundle
- Docs include a playground and a licensing page
- Each framework adapter has an example app

## 0.0.1 — 31 Oct 2026

You can embed the viewer and open PDF and Office files from a CDN.

- Select, highlight, comment, and download the open file
- React, Vue, Svelte, Angular, Solid, Preact, and Lit adapters
- PDF and Office engines load from a CDN, not this repo
- An unsupported action returns a detail instead of failing quietly
