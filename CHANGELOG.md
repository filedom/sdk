# Changelog

## 0.0.3 — 31 Oct 2026

The docs send you back to the site on this domain.

## 0.0.2 — 31 Oct 2026

You can copy a UI kit into a framework app and open files from a versioned CDN.

- A headless store drives the viewer without painting the page
- The PDF renderer is read from inside the pdf bundle
- Docs include a playground and a licensing page
- Each framework adapter has an example app

## 0.0.1 — 31 Oct 2026

You can embed the viewer and open PDF and Office files from a CDN.

- Select, highlight, comment, and download the open file
- React, Vue, Svelte, Angular, Solid, Preact, and Lit adapters
- PDF and Office engines load from a CDN, not this repo
- An unsupported action returns a detail instead of failing quietly
