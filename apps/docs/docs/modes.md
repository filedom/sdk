# Modes

The mode menu is on every file, and the same choice is in Settings under Editing. Track mode stores the change list for PDF, Word, Excel, and PowerPoint. Other formats report track changes as unsupported. [Toolbars](/sdk/docs/toolbars) lists Restore, Revert, and the rest of that toolbar.

| Mode | Behavior |
| --- | --- |
| `live` | Selection and edits. History list is hidden; the page shows the current document. |
| `track` | Selection and edits. The history list shows each change. Text documents draw insertions and deletions on the page. |
| `view` | Read-only. Editing controls stay visible and disabled when the format supports them. |

There is no PDF View/Edit switch and no second page-mode control.
