# UI kit

`@filedom/ui` is a copy-in component kit in the shadcn style. It ships a Tailwind v4 theme and one source set per framework: a toolbar, zoom controls, search, mode select, theme toggle, file button, and page status. The components sit on top of the headless viewer store from `@filedom/core`. Run `npx @filedom/ui init` once, then `npx @filedom/ui add <block>` to copy a block into your project, where you can edit it.
